# 0.4.0 Preview 1 — release validation

23 October 2026. Product source: `f0f2398348278a00458f4817a17c53777e7c70fe`.
Version `0.4.0-preview.1`, signed channel sequence `6`.
CEF `156.0.8+g426920c+chromium-156.0.8078.48`, both x64 platforms.

## Build and runtime

- Official CEF index sizes and SHA-1 values were checked before pinning SHA-256 in the dependency lock.
- Linux host and Debian 13 builds: 122 CTest entries, zero failures. The optional external Web Store package test was skipped without its fixture; this is not a claim that every Chrome extension works.
- All 33 default GUI suites passed against the new engine on a private Weston Pixman/Xwayland SHM display, with GLX disabled. No GPU test ran on the desktop.
- Coverage includes all 15 features, actual five-minute automatic sleeping, popup/opener/history, Unicode clipboard, API/CSP/CORS/TLS/WebM compatibility, raster edges and scrolling, interface scaling, settings, import/vault, extensions, windows and filter updates.
- Windows build, unit/integration tests, portable packaging and branded installer install/reinstall/remove/profile retention passed in [CI 39952387746](https://github.com/Sttanors/aura-browser/actions/runs/39952387746).

## Installers

- Native runtime was rebuilt against the Debian 13 ABI. The development machine's newer ABI binary was not repackaged into the DEB.
- Debian 13, Arch and Fedora 44: real package-manager install/reinstall/remove, dependencies, launcher version, icons/desktop entry, root ownership, stale per-user launcher migration and profile preservation passed in disposable containers.
- Debian-built runtime also passed the real browser GUI and raster full/page-only comparison at 75–200%, dark/light and device scale 1/1.25.
- Actual signed published `.run` 0.3.0-preview.1 → new `.run` 0.4.0-preview.1 passed: exact new executable, bookmarks/history/settings, cookies/localStorage and profile marker retained. Uninstall retained the profile. Test HOME/XDG paths included spaces, Cyrillic and shell-special characters.
- All seven binary artifacts have verified SHA-256 sidecars. Local Ed25519 signing matches the compiled public key. The private key remained local and was not added to CI secrets or release files.
