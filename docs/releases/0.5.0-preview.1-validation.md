## Limits

Wayland is opt-in; X11 remains the default. Physical mixed-DPI displays, external
IME candidate windows, hardware GPU rendering and every compositor are not claimed
as validated. Document unloading loses the DOM and per-tab back/forward history;
shared Chromium caches/processes may remain. Temporary click-to-grant activeTab
is unavailable in CEF OSR. Windows publisher signing is unavailable; the update
channel is signed separately with the existing local key. No private key, profile,
test input module or clipboard peer is shipped.
