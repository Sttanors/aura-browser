# Aura 0.4.0 Preview 2

## Русский

Исправлено отсутствие Firefox в списке «Обнаруженные профили» при импорте.
Aura теперь ищет профили также в `~/.config/mozilla/firefox` (или пользовательском
`$XDG_CONFIG_HOME/mozilla/firefox`), Firefox Snap и новом расположении Flatpak.
Старые расположения по-прежнему поддерживаются; ссылки на один профиль не создают
повторных пунктов. Наличие оставшегося файла блокировки не скрывает профиль.

После обновления откройте **Настройки → Данные → Импорт данных браузера →
Обнаруженные профили** и выберите Firefox. Предпросмотр позволяет выбрать закладки
и историю перед импортом. Пароли, cookies и расширения Firefox не импортируются.
Закройте Aura перед установкой обновления; существующий профиль сохраняется.

Движок и остальные функции соответствуют 0.4.0 Preview 1. Установщики Windows,
Linux `.run`, `.deb`, `.rpm`, Arch `.pkg.tar.gz` и portable ZIP обновлены.
Контрольные суммы и канал обновлений подписаны; доверенной подписи издателя
Windows пока нет. Проект разработан с существенной помощью ИИ — OpenAI Codex.

## English

Fixed Firefox missing from **Detected profiles** during browser data import.
Aura now also searches `~/.config/mozilla/firefox` (or a custom
`$XDG_CONFIG_HOME/mozilla/firefox`), Firefox Snap and the newer Flatpak location.
Legacy locations remain supported. Linked copies of a profile appear once;
leftover Firefox lock files do not hide profiles.

After updating, open **Settings → Data → Import browser data → Detected profiles**
and select Firefox. Preview and choose bookmarks/history before applying.
Firefox passwords, cookies and extensions are not imported. Close Aura before
updating; your existing Aura profile is retained.

The engine and other features match 0.4.0 Preview 1. Windows installers, Linux
`.run`, `.deb`, `.rpm`, Arch `.pkg.tar.gz` and portable ZIPs are updated.
Checksums and the update channel are signed; a trusted Windows publisher signature
is not available yet. Developed with substantial AI assistance from OpenAI Codex.
