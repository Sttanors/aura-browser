# Aura 0.5.0 Preview 1

## Русский

Этот выпуск объединяет исправления аудита и все 15 последующих улучшений.

- Масштаб сайтов с учётом контейнеров и автоматические правила контейнеров.
- Менеджер загрузок с повтором/управлением и диспетчер процессов Chromium.
- «Прочитать позже», офлайн-статьи и пользовательские поисковые системы.
- Просмотр и очистка дубликатов, дерево вкладок, горизонтальная панель на выбор,
  перенос живых вкладок между окнами без перезагрузки.
- Локальная орфография RU/EN, пользовательский словарь и управление постоянным
  доступом расширений к сайтам. Временный activeTab по нажатию пока недоступен в CEF OSR.
- Безопасный режим диагностики с отключением расширений/внедрений и обезличенным
  локальным отчётом.
- Экспериментальный нативный Wayland: `--window-system=wayland`. X11 остаётся по
  умолчанию. Добавлены SHM raster, clipboard, IME, файловые диалоги и перенос вкладок.
- Реальная выгрузка неактивных документов: **Настройки → Вкладки → Действие для
  неактивных вкладок** или **Ctrl+K → Выгрузить неактивные вкладки**. При выборе
  выгруженная страница загружается заново, история переходов вкладки сбрасывается.
  Формы, медиа, загрузки и другие защищённые страницы остаются открытыми.
  Заморозка и выключенный таймер сохранены по умолчанию.

Исправлены папки при импорте, экспорт локальных закладок, отказ сна со сменой
фокуса, проверка домашнего URL, регистр кириллицы в снимках сессий и блокировка
сна соседней вкладки при загрузке файла.

Закройте Aura перед обновлением. Профиль сохраняется. Пакеты: Windows setup/ZIP,
Linux `.run`/ZIP, Debian `.deb`, Fedora `.rpm`, Arch `.pkg.tar.gz`, контрольные суммы
и подписанный канал обновлений. Доверенной подписи издателя Windows пока нет.
Нативный Wayland остаётся preview: аппаратные мониторы с разным DPI, внешние окна
кандидатов IME и все compositor не проверены. Полного аудита безопасности не заявляется.

## English

This release brings together the audit fixes and all 15 follow-up improvements.

- Per-site/container zoom and automatic container routing rules.
- Improved downloads with retry/controls, and a Chromium process manager.
- Reading list, offline articles and custom search engines.
- Duplicate review/cleanup, tree tabs, an optional horizontal tab bar and live
  cross-window tab transfer without reloading.
- Local Russian/English spelling, a custom dictionary and persistent extension
  site permissions. Temporary click-to-grant activeTab remains unavailable in CEF OSR.
- Safe diagnostic mode that pauses extensions/injections and exports a sanitized
  local report.
- Experimental native Wayland via `--window-system=wayland`, including SHM raster,
  clipboard, IME, file choosers and tab dragging. X11 remains the default.
- Real document unloading: **Settings → Tabs → Inactive tab action**, or
  **Ctrl+K → Unload inactive tabs**. Selecting an unloaded tab reloads it and
  resets its back/forward history. Forms, media, downloads and other protected
  pages stay loaded. Freeze remains the default action; the timer stays off by default.

Fixed imported bookmark folders, local bookmark export, rejected sleep changing
focus, home URL validation, Cyrillic session-name case handling and a download
incorrectly preventing a neighbouring tab from sleeping.

Close Aura before updating. Your profile is retained. Downloads include Windows
setup/ZIP, Linux `.run`/ZIP, Debian `.deb`, Fedora `.rpm`, Arch `.pkg.tar.gz`, checksums
and signed update-channel metadata. A trusted Windows publisher signature is not
available yet. Native Wayland remains a preview: physical mixed-DPI monitors,
external IME candidate windows and every compositor have not been validated.
This is not a complete security audit.
