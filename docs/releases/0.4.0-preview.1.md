## Русский

Этот релиз переносит все 15 новых функций из исходников в установщики:

- Рабочие пространства и группы вкладок с сохранением живых страниц.
- Спящие фоновые вкладки и две страницы рядом.
- Контейнеры сайтов с отдельными cookies и полноценные профили браузера.
- Палитра команд, режим чтения и онлайн-перевод только по явной команде с выбором провайдера.
- Центр разрешений сайта и управление его cookies/хранилищами.
- Менеджер закладок: папки, теги, массовые операции, отмена удаления, HTML-импорт/экспорт.
- Именованные снимки сессий с восстановлением в новых окнах.
- Скриншоты видимой части, выделенной области и всей страницы в PNG (`Ctrl Shift S`).
- Настройка 34 горячих клавиш, поиск команд, защита от конфликтов и сброс назначений.

Движок обновлён до **CEF 156 / Chromium 156.0.8078.48**. Исправлены восемь ошибок исходного аудита: восстановление профиля, предупреждения при выходе, popup/opener, история новой вкладки, отменённое закрытие, адреса IPv6/локальные порты, большая вставка X11 и миграция Linux-установок.

Закройте Aura перед обновлением. Профиль сохраняется. Для `.run`: `bash ~/Downloads/aura2-linux64.run` без sudo. Для системных пакетов используйте apt/dnf/pacman. При переходе с `.run` на системный пакет сначала удалите прежнюю пользовательскую установку командой `~/.local/bin/aura-browser-uninstall` — профиль останется.

В assets — установщики/portable, SHA-256 и подписанные `aura-update.toml` / `.sig`. Исходники доступны стандартными GitHub Source code ZIP/tar.gz. Логотипы включены в установщики.

Ограничения preview: нет доверенной подписи издателя Windows (подпись канала обновлений — отдельная защита); H.264/HEVC/Widevine не включены. Полная совместимость Chrome extensions не заявляется. Linux использует X11/Xwayland и программную отрисовку; нативный Wayland и стабильное GPU-ускорение не реализованы. Вся страница на скриншоте ограничена 32 Мп / 32766 px на сторону с уменьшением; это не ограничивает фон начальной страницы.

Проверки: 33 GUI-набора Linux на новом движке, Windows build/integration/installer CI, реальные пакетные менеджеры Debian/Arch/Fedora и обновление `.run` с 0.3.0 с сохранением данных. [Протокол выпуска](https://github.com/Sttanors/aura-browser/blob/main/docs/releases/0.4.0-preview.1-validation.md).

Проект разработан с существенной помощью ИИ — **OpenAI Codex**. [Журнал 15 функций](https://github.com/Sttanors/aura-browser/blob/main/docs/features-progress.md).

## English

This release brings all 15 source additions into the installers:

- Workspaces and tab groups that retain live pages.
- Sleeping background tabs and two pages side by side.
- Site containers with separate cookies, and full browser profiles.
- Command palette, reader view and explicit online translation with provider choice.
- Site permission center and cookie/storage management.
- Bookmark folders/tags, bulk actions, deletion undo and HTML import/export.
- Named session snapshots restored into additional windows.
- Visible-area, region and full-page PNG screenshots (`Ctrl Shift S`).
- Remapping 34 keyboard commands with search, conflict protection and reset.

The engine is now **CEF 156 / Chromium 156.0.8078.48**. The eight audit fixes cover profile recovery, exit prompts, popup/opener behavior, new-tab navigation history, cancelled closure, IPv6/local addresses, large X11 pastes and Linux installation migration.

Close Aura before upgrading. Profiles are retained. Run `.run` with `bash ~/Downloads/aura2-linux64.run` as your regular user. Use apt/dnf/pacman for native packages. Before switching from `.run` to a system package, run `~/.local/bin/aura-browser-uninstall`; this retains your profile and removes the old per-user launcher.

Assets contain installers/portable archives, SHA-256 and signed `aura-update.toml` / `.sig`. GitHub provides source ZIP/tar.gz automatically. Logos are embedded in the installers.

Preview limits: no trusted Windows publisher signature (update-channel authentication is separate); H.264/HEVC/Widevine are not included. Full Chrome extension compatibility is not claimed. Linux uses X11/Xwayland and software rendering; native Wayland and stable GPU acceleration are not implemented. Full-page PNGs are downscaled to 32 MP / 32766 pixels per side; start-page wallpaper is unaffected.

Validation: 33 Linux GUI suites on the new engine, Windows build/integration/installer CI, actual Debian/Arch/Fedora package managers and a profile-preserving `.run` upgrade from 0.3.0. [Release validation](https://github.com/Sttanors/aura-browser/blob/main/docs/releases/0.4.0-preview.1-validation.md).

Developed with substantial AI assistance from **OpenAI Codex**. [15-feature journal](https://github.com/Sttanors/aura-browser/blob/main/docs/features-progress.md).
