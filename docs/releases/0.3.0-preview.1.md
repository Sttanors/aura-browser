## Русский

Новая сборка включает результаты пунктов 1–8 из журнала работ:

- Подписанный канал обновлений, проверка хешей и установка после закрытия CEF.
- Импорт закладок/истории Firefox и Chromium, хранилище паролей с заполнением HTTPS-логинов по нажатию и зашифрованным ручным переносом.
- Проверка обновлений MV3, просмотр новых разрешений и перезапуск с сохранением обычных вкладок.
- Отдельные обычные/приватные окна, восстановление окон/вкладок и восстановление после незавершённого выхода.
- Обновление EasyList/EasyPrivacy, свои правила, импорт и восстановление встроенных списков; поддерживаемые процедурные фильтры, removeparam и локальные подмены ресурсов.
- Улучшенная программная отрисовка больших страниц, неблокирующее чтение частоты Wayland, согласованные версии всех установщиков.

Проверены Windows portable/установщик и Linux-пакеты Debian 13+, Arch/CachyOS и Fedora 44.
Проверены реальные API, WebM, границы CSP/CORS/TLS и сохранение данных при обновлении старого `.run`.

При обновлении с preview.3.1 закройте Aura и установите эту версию вручную один раз — в старой опубликованной версии нового updater ещё не было. Профиль сохраняется. Если переходите с `.run` на системный пакет, сначала удалите прежнюю пользовательскую установку её командой удаления; профиль останется.

В assets находятся установщики/portable, SHA-256 и служебные `aura-update.toml`/`.sig` для встроенного updater. Исходники доступны стандартными GitHub Source code ZIP/tar.gz; логотипы включены в runtime.

Ограничения: H.264, HEVC и Widevine не доступны в поставляемом runtime. Проверен WebM VP9+Opus. Native Wayland и стабильное Linux GPU-ускорение не реализованы; стандартный Linux режим использует X11/Xwayland и CPU. Полная совместимость Chrome extensions не заявляется. Подпись канала не является доверенной подписью издателя Windows.

Проект разработан с существенной помощью ИИ — OpenAI Codex. Подробные результаты и границы проверок: [журнал](../browser-roadmap-progress.md), [матрица совместимости](../compatibility.md).

## English

This preview ships the work recorded in roadmap items 1–8:

- Signed updates with exact hash verification and installation after CEF shutdown.
- Firefox/Chromium bookmark/history import, a master-password vault, explicit HTTPS login filling and encrypted manual transfer.
- MV3 update checking, added-permission review and restart with normal-tab restoration.
- Separate normal/private windows, multi-window session restoration and interrupted-exit recovery.
- EasyList/EasyPrivacy updates, custom rule editing/import and bundled recovery; supported procedural filters, removeparam and local resource replacements.
- Faster software drawing of large pages, nonblocking Wayland refresh discovery and consistent installer/package versions.

Windows portable/installer and Debian 13+, Arch/CachyOS and Fedora 44 packages were tested.
API, WebM, CSP/CORS/TLS boundaries and an actual previous-release `.run` upgrade were exercised.

Close Aura and manually install this release once when upgrading from preview.3.1: that published build did not contain the new updater. Profiles are retained. When switching from `.run` to a native package, remove the previous per-user installation with its uninstaller first; the profile remains.

Assets include installers/portable archives, SHA-256 and `aura-update.toml`/`.sig` for the updater. GitHub provides source ZIP/tar.gz automatically. Logos are embedded in the runtime rather than separate downloads.

Limits: H.264, HEVC and Widevine are unavailable in the supplied runtime; WebM VP9+Opus is verified. Native Wayland and stable Linux GPU acceleration are not implemented; the default Linux path is X11/Xwayland on CPU. Full Chrome extension compatibility is not claimed. Channel signing is separate from a trusted Windows publisher signature.

Developed with substantial AI assistance from OpenAI Codex. See the [progress journal](../browser-roadmap-progress.md) and [compatibility matrix](../compatibility.md) for evidence and limits.
