### B1 — реализация

Поиск существующей папки использует ту же нормализацию регистра RU/EN и пробелов,
что и её создание. Ошибка создания папки прерывает импорт с понятным сообщением
RU/EN, вместо помещения записей «Без папки». Работа идёт с копией профиля, поэтому
ошибка сохраняет исходный профиль. Добавлены регрессии настоящего HTML-импорта:
сопоставление двух регистров, сохранение после перезапуска и атомарный отказ при
лимите 128 папок. Сборка Linux PASS. Пять тестов `Imports.*Folder*` PASS, включая
новые регрессии, повторную загрузку профиля и сохранность TOML при отказе.

### B2 — реализация

Сохранение, редактирование и экспорт используют общий список разрешённых схем,
включая file://, about:blank и страницы установленных расширений. Исполняемые
javascript:/data: адреса не сохраняются. HTML экранирует URL и подписи. Если старый
профиль всё же содержит неподдерживаемые адреса, экспорт показывает их число до
выбора файла. Добавлена регрессия сохранения/редактирования/экспорта локального
документа после перезапуска, сохранения тегов и точного числа исключённых адресов.
Linux build, 4 Bookmarks-теста и изолированный GUI bookmarks PASS: нативный Save,
отмена, UTF-8 путь, экранирование HTML, массовые действия, RU/EN и повторный запуск.

### B3 — реализация

Команда сначала проверяет исключения, захват/воспроизведение медиа и состояние
страницы. Переключение на другую вкладку или создание стартовой вкладки, а также
выход из split выполняются только после успешного подтверждения freeze от CEF.
Добавлены GUI-регрессии: отказ для домена из исключений и Web Audio сохраняет
активную вкладку и количество вкладок.
Изолированный GUI manual/exceptions PASS: реальный freeze/wake, неподвижный таймер,
сохранение формы/beforeunload, освобождение bitmap, отказ для media/domain без
смены фокуса. Старый сценарий приватной вкладки больше не зависит от лишней NTP.

### B4 — реализация

Домашняя страница использует тот же разбор authority, что и адресная строка:
проверяются hostname, IPv6, порт и управляющие символы. Явный HTTP/HTTPS сохраняет
поддержку локальных имён без точки; некорректный ввод не заменяет прежнюю настройку.
Добавлены проверки ошибочных IPv6/портов/IPv4/hostnames и корректных localhost,
intranet, IPv4, IPv6 и кириллического домена.
Linux build и полный CTest: 127 entries, 0 failures (8,65 с).

### B5 — реализация

Снимки, поиск/отмена удаления в UI и папки закладок используют общий независимый
от locale helper регистра RU/EN (включая Ё/ё). Другие UTF-8 символы сохраняются;
полный Unicode case folding для остальных языков не заявляется. Старые снимки с
различием только в регистре кириллицы не удаляются: при чтении добавляется свободный
суффикс имени с сохранением ID, окон и URL. Добавлены регрессии создания,
переименования, миграции двух старых снимков и повторного сохранения/загрузки.
Linux build, 9 Sessions/Bookmarks tests и GUI sessions PASS: save/rename/update,
delete/undo, настоящее восстановление в новых окнах, перезапуск, контейнеры,
split, RU и запрет приватных снимков.

### B6 — воспроизведение и реализация

Новый `download-sleep` GUI-сценарий запускает настоящую медленную HTTP-загрузку.
До исправления соседняя вкладка отказалась засыпать: source/target sleeping=false,
скачано 2 539 520 байт, загрузка не завершена. Причина подтверждена.
У загрузки теперь сохраняется вкладка-источник из CEF callback. Защита сна относится
к ней; источник без определённого ID консервативно защищает все вкладки до привязки.
Тот же сценарий после сборки должен проверить сон соседней страницы, продолжающуюся
загрузку и отказ сна источника без смены фокуса.

После исправления GUI download-sleep PASS: target sleeping=true, source=false,
скачано 671 744 байта; скачивание продолжалось. Отказ сна источника не меняет фокус.

### 1 — запоминание масштаба сайта: реализация

[Использование RU/EN](site-zoom.md).

Масштаб хранится по canonical hostname и контейнеру (схема/порт не разделяются,
как у нативного host zoom Chromium). Применяется в новых вкладках, при навигации
и после перезапуска; открытые страницы того же хоста/контекста обновляются вместе.
Ctrl 0 удаляет переопределение и использует масштаб по умолчанию. Переключатель
«Запоминать масштаб для каждого сайта» находится в «Веб-страницы» и действует
сразу. Приватные значения хранятся отдельно в BrowserState, не попадают в TOML.
Schema15, до 1000 правил, проверка host/container/finite level и очистка правил
при удалении контейнера. Linux build и 129 CTest PASS (8,77 с).
GUI site-zoom PASS: настоящий CEF 100/120/144/83%, другой хост, новые вкладки,
контейнеры, private isolation, Ctrl 0, отключение/включение из RU UI и три запуска.
Приватный URL и значение не попали в TOML/backup. Подпись настройки проверена
визуально; отдельная панель и дополнительные декоративные индикаторы не добавлялись.
