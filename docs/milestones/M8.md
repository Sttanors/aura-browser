# M8 — масштаб интерфейса Linux

85-я настройка: Внешний вид → Масштаб интерфейса, 75 / 80 / 90 / 100 / 110 / 125 / 150 / 175 / 200%.
Профиль сохраняет ui_zoom; настройка применяется сразу, при запуске и изменении окна.
Нативные элементы, текст и OSR-панель расширения масштабируются согласованно.
Ctrl Shift 0 сбрасывает выбранное значение до 100%.

Физический размер окна сохраняется. Эффективный коэффициент ограничен минимальной логической
областью 900×620; уменьшение окна не скрывает настройки. Показывается применённый процент,
выбранный восстанавливается при расширении окна. Минимальное физическое окно — 675×465 при DPI 1.

CEF сайта сохраняет базовый device_scale_factor и собственный zoom. Размер его viewport
пересчитывается в независимые координаты сайта; ввод, IME, контекстное меню и select-popup
преобразуются между координатами chrome и сайта. Расширение использует масштаб chrome.

Проверки: CTest; scripts/verify_browser.py --suite=interface на закрытом Weston Pixman/Xwayland SHM
без GLX. 75–200%, малое/большое окно, RU/EN, ввод и переходы CEF, независимый zoom сайта/NTP,
сохранение, перезапуск с device scale 1.25. Отдельный features suite проверяет OSR-расширение
при 125% (ввод, диалог, storage/message), закрепление, остальные средства защиты и жизненный цикл.
