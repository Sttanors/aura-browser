# M5 — popup расширения поверх страницы и закреплённые иконки

Кнопка «Открыть» в менеджере и закреплённая иконка теперь открывают `action.default_popup`
поверх страницы в текущем окне Aura. Popup не добавляется в список вкладок, историю
и восстанавливаемую сессию. Страница параметров расширения остаётся обычной вкладкой.

## Поведение

- Отдельная CEF OSR-поверхность отрисовывается в Skia-карточке под панелью браузера.
  Полноэкранного затемнения страницы нет. Заголовок содержит имя, иконку, булавку и закрытие.
- CEF auto-resize подстраивает размер под документ, включая последующие изменения DOM.
  Размер ограничен окном браузера; при изменении размера окна popup остаётся внутри него.
- Мышь, прокрутка, текст, клавиатура и IME направляются в popup. JS alert/confirm/prompt
  показываются собственным диалогом Aura. Escape, клик снаружи,
  повторное нажатие иконки, потеря фокуса, переход страницы и смена вкладки закрывают popup.
- `window.close()` закрывает popup; внешние HTTP(S) ссылки открывают обычную вкладку Aura.
  Дополнительные окна сайта из popup допускаются только после user gesture и маршрутизируются во вкладки.
- Открытие/закрытие асинхронны: закрывающаяся поверхность живёт до OnBeforeClose.
  При выходе Aura ждёт завершения всех popup перед CefShutdown.
- Закрепление доступно в карточке менеджера, заголовке popup и контекстном меню иконки.
  Оно сохраняется сразу в реестре и переносится при обновлении расширения.
- Иконки берутся из `action.default_icon`, затем `icons`. Старые записи реестра без
  поля icon используют manifest. PNG проверяется по размеру до декодирования Chromium.
  При отсутствующей/неподдерживаемой иконке используется встроенный значок расширения.
- Адресная строка оставляет место под закреплённые иконки. При недостатке ширины остальные
  остаются доступны в менеджере. Отключённые расширения убираются с панели, сохраняя закрепление.
- Приватные вкладки не получают popup обычного профиля. Кнопки и тексты доступны на RU/EN.

## Проверки 19.10.2026

- Release Linux собран. CTest 33/33.
- Подписанный MV3 fixture содержит реальную PNG-иконку и интерактивный popup:
  ввод, сохранение в chrome.storage.local, runtime messaging и изменение размеров документа.
- Изолированный GUI-сценарий features: 4 запуска, CPU-only Weston Pixman / Xwayland SHM.
- Проверено отсутствие новой вкладки и дополнительного видимого окна Aura при открытии popup.
- Пройдены ввод/клики, Alt+Shift без закрытия popup, собственный JS confirm, storage/messaging,
  auto-resize, Escape, клик снаружи, повторный клик иконки,
  булавка/открепление из заголовка, кнопка закрытия и window.close().
- Popup проверен при 1360×900 и 900×620; снимки визуально просмотрены.
- Закрепление пережило перезапуск, собственная иконка декодировалась; выключение расширения
  скрыло иконку, сохранив её закрепление в реестре. Unit-проверка покрывает обновление пакета.
- Приватная вкладка не открыла popup. Закрытие основного окна с открытым popup завершило
  все CEF callbacks; счётчики открытия/закрытия popup сбалансированы, renderer crashes 0.
- Повторно проверены adblock, Dark Reader, signed CRX review, MV3 worker/storage/DNR,
  отключение/удаление после перезапуска и загрузка из Chrome Web Store.

Код: core/browser/extension_popup.cpp, extensions.*, browser.*, ui/browser_ui.*.
Сценарий: python3 scripts/verify_browser.py --suite=features.
Отчёты: artifacts/features-smoke/verification.json и artifacts/build/extension-overlay-*.log.
Снимки: artifacts/features-smoke/extension-overlay*.png, extensions-pinned.png.

Ограничения Chrome API в CEF Alloy остаются прежними: это представление настоящей страницы
расширения в собственном интерфейсе Aura, без эмуляции chrome.tabs и панели Chrome.
