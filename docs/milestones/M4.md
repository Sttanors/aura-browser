# M4 — защита сайтов и расширения MV3

## Реализация

- Нативная блокировка запросов через Brave adblock-rust 0.13.3, EasyList и EasyPrivacy.
  Движок разделяется между CEF UI / IO threads с синхронизацией. Проверяются тип ресурса,
  адрес запроса и адрес основной страницы; верхнеуровневая навигация не блокируется.
- Обычные косметические CSS-фильтры: правила домена, общие class / id selectors,
  динамические элементы и исключения `$generichide`. DOM обход ограничен по частоте и размеру.
- Dark Reader 4.9.133: динамическая тема, включение / выключение / следование теме Aura,
  яркость, контраст, сепия, исключения доменов. Параметры меняются без перезагрузки.
- Скрипты работают через внутреннюю CEF DevTools session в isolated world; наружу не
  открывается remote debugging. CSP и web security глобально не отключаются.
- Кнопка щита: общий счётчик, исключения для текущего сайта, быстрый Dark Reader и настройки.
- Кнопка пазла: собственный Skia-менеджер расширений. Ввод URL / ID магазина Chrome
  или абсолютного пути к CRX3. На странице расширения CWS есть «Установить в Aura».
- Установщик проверяет подпись RSA / ECDSA SHA-256, signed ID и hash публичного ключа;
  для загрузки из магазина ID должен совпадать с запрошенным. Защищённая распаковка
  запрещает выход из каталога, symlinks, hardlinks, дубликаты и чрезмерные размеры.
- Перед установкой показываются manifest permissions, host permissions и content-script matches.
  Сохранение ключа из подписанного CRX сохраняет исходный ID при загрузке через CEF.
- Включение / отключение / удаление / повторная установка для обновления; popup и options
  открываются как страницы расширения. Изменения требуют перезапуска Aura.
- 8 новых параметров защиты, 69 настроек всего, 9 разделов. Новые элементы переведены RU / EN.

## Файлы

- core/adblock/ — Rust FFI static library, точный Cargo.lock.
- core/browser/protection.* — общий движок, исключения и адаптер типов ресурсов CEF.
- core/browser/site_tools.cpp, devtools.* — isolated scripts, контексты и управление Dark Reader.
- core/browser/extensions.* — реестр, загрузка, проверка CRX3 и распаковка.
- resources/protection/ — списки, скрипт и upstream SHA-256.
- resources/vendor/ — Dark Reader, лицензии и атрибуция зависимостей.
- scripts/smoke_features.py — сценарий настоящего браузера на отдельном CPU-дисплее.
- tests/protection_tests.cpp — правила, исключения, подписи, ID, архивы и реестр.

## Ограничения

CEF OSR работает в Alloy style. Startup MV3 поддерживается, но Chrome tabs / toolbar API
могут отсутствовать или возвращать пустой список. CDP Extensions.loadUnpacked в этой конфигурации
возвращает Method not available; установленное расширение загружается при следующем запуске.
Совместимость со всем Chrome Web Store не заявляется. Доступ приватным вкладкам не включается.

Списки поставляются локальными снимками; автообновления списков и расширений пока нет.
Scriptlet / procedural filters и redirect resources не подключены. Блокировка всей видеорекламы
не гарантируется. GPU в обычном режиме выключен; тесты на реальном пользовательском дисплее
не проводились, пользовательский профиль не изменялся.
