# M7 — динамические ссылки, фон и автоматическая палитра

## Ссылки

- Отдельный список в profile.toml (schema 4), до 1000 записей, без ограничения тремя слотами.
- Старые ntp_link_1/2/3 мигрируют при отсутствии массива shortcuts. Пустые прежние слоты
  не создают записей. Пустой новый массив остаётся пустым после перезапуска.
- Кнопка «Быстрые ссылки»: название (необязательно), http(s)-адрес, добавление / изменение,
  удаление с отменой последнего удаления, стрелки порядка. Есть меню правой кнопки на карточке.
- Общая разметка карточек для отрисовки и кликов, от 1 до 6 колонок, автоматическая компоновка,
  прокрутка. Менеджер работает с клавиатуры, поля имеют видимый фокус и сохраняются при ошибке.

## Изображение и тема

- PNG / JPEG с компьютера через системный Zenity либо поле абсолютного пути.
- Асинхронный запуск без shell, неблокирующее чтение результата, закрытие дочернего процесса
  с браузером. GTK использует X11 / Cairo и software rendering. Если Zenity отсутствует,
  работает поле пути. Исходное изображение не изменяется и не отправляется в сеть.
- В профиле сохраняется отдельная копия wallpaper.png/jpg. Замена удаляет старую управляемую
  копию другого формата; очистка удаляет только известные файлы фона внутри профиля.
- Лимиты 20 МБ / сторона 8192 px (ограничение 16 МП впоследствии снято) проверяются по заголовку до декодирования Chromium.
  Для рисования хранится кэшированный SkImage со стороной до 1920 px; нет копирования
  полного буфера изображения на каждый кадр. Повреждённое новое изображение сохраняет старый фон.
- Cover / contain, затемнение 0–80%, общая полупрозрачная подложка для читаемости содержимого.
- Палитра по преобладающим цветам с учётом насыщенности, два набора для светлого / тёмного
  режима, подбор контраста акцента. Автопалитра меняет всю оболочку, пока включён фон изображения.
  Выключение автопалитры возвращает выбранную тему и акцент. Всего 84 настройки.

## Проверки

- Release Linux, CTest 35 тестов. Новый тест миграции / порядка / сохранения / пустого списка;
  небезопасные протоколы отклоняются.
- `--suite=wallpaper`: два запуска в Weston Pixman / Xwayland SHM без GLX.
- 10 ссылок через реальные поля, UTF-8 названия, ошибка javascript:, изменение / порядок /
  удаление / отмена; сохранение порядка после перезапуска.
- Настоящий GTK-диалог выбирает PNG с кириллицей и пробелами в имени; повторный выбор отменяется.
- JPEG через поле пути; смена изображения меняет палитру; выключение / включение автопалитры,
  WCAG contrast >= 4.5 для текста и акцента по эффективным цветам, светлый / тёмный режим.
- Подделанный PNG с огромными размерами отклонён до декодирования, старый фон сохранён.
- Исходники тестовых изображений удалены; копия работает после перезапуска. Очистка удаляет
  управляемый фон. 1360×900 / 900×620, RU / EN, balanced CEF lifecycle.
- Общие регрессии: browser, settings, startpage, wallpaper, features.

Отчёты: artifacts/wallpaper-smoke/verification.json, artifacts/build/wallpaper-*.log.
Снимки: shortcuts-10-ru.png, warm-auto-theme.png, cool-auto-theme.png, photo-small-ru.png,
photo-light.png, native-chooser.png, image-validation.png в artifacts/wallpaper-smoke.

После снятия ограничения 16 МП GUI-сценарий использует PNG 6000×4000 (24 МП) и JPEG 7680×4320 (33,2 МП).
