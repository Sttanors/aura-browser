# M9 — вывод кадров при прокрутке Linux

Устранены лишние перерисовки и задержки программного вывода. Chromium уже выдавал плавную
анимацию колёсика; проблема была в стоимости и доставке кадров оболочки.

- Raster surface окна сохраняется между кадрами, выделяется снова только при изменении размеров.
- OnPaint активной страницы помечает её область; XPutImage отправляет эту область вместо всего окна.
- В обычном режиме перерисовывается содержимое сайта, сохраняя вкладки, тулбар и боковую панель.
  Фон под скруглениями хранится отдельно и восстанавливается перед каждым кадром, чтобы
  полупрозрачные границы не темнели от повторного смешивания.
- Для CPU canvas убрана промежуточная копия CEF bitmap; отрисовка синхронна на том же UI thread.
  Экспериментальный GPU путь сохраняет независимую копию и полную отрисовку.
- Движение мыши и колесо внутри сайта не перерисовывают всю оболочку; изменения статуса ссылки
  обновляют её только при изменении текста. Нативные панели, поиск, диалоги, меню и расширения
  используют полный painter, чтобы сохранять порядок наложения и фокус.
- PumpSchedule пробуждает poll окна через eventfd при появлении более ранней задачи CEF,
  включая задачи из других потоков. Callback вызывается без удержания mutex.

Новые диагностические поля presentation: paint_ms_p95 (последние 240 отрисовок, без ожидания
физического показа композитором), raster_allocations, content_frames, presented_pixels.

Проверка: 36 unit-тестов; private Weston Pixman + Xwayland SHM, GLX выключен.
Scrolling suite измеряет настоящую CEF-анимацию без JS-перехвата колеса: вертикальная прокрутка
в обе стороны, серия событий, вложенная область, горизонтальная область и UI zoom 125%.
В большом окне 2200×1500 серия из 16 событий дала 48 разных положений против 40 до изменения;
CPU процесса оболочки — 680 мс против 830 мс в этом тестовом прогоне, 49 native presentations
против 43. Эти числа относятся к изолированному CPU дисплею, а не гарантированной частоте
на произвольном сайте или пользовательском оборудовании. Буфер окна выделился дважды за
весь тест: исходный размер и увеличение окна, а не на каждый кадр.

Дополнительно: browser и features GUI suites проверяют навигацию, ввод, диалоги, защиту,
закрепление и OSR-оверлей расширения, включая масштаб 125%, приватные вкладки и закрытие CEF.
