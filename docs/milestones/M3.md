# M3 — расширенный каталог настроек

Вместо трёх небольших разделов реализован каталог из 61 настройки с восемью категориями и
поиском по русским / английским названиям, описаниям и идентификаторам. Каталог общий для UI,
валидации, загрузки / сохранения профиля и диагностического JSON. Каждая настройка связана
с поведением оболочки, CEF BrowserSettings, ContentSettings или обработчиками запросов.

## Что добавлено

- **Основные:** домашняя страница, запуск с новой / домашней страницей, пустая / домашняя новая
  вкладка, язык сайтов; прежние язык UI, поисковик и восстановление сессии.
- **Вкладки:** фоновое открытие ссылок, вставка рядом, выбор после закрытия, подтверждение выхода,
  средняя кнопка, колесо переключения, начальный mute и выход с последней вкладкой.
- **Внешний вид:** значки сайтов, предпросмотр адресов, часы 12/24, приветствие; прежние темы,
  быстрые ссылки, подписи вкладок и уменьшение анимации.
- **Веб-страницы:** масштаб, размеры обычного / моноширинного шрифта и минимум, семейство шрифта,
  JavaScript, изображения, remote fonts, Local Storage, resize textarea, Tab links и fit images.
- **Приватность:** срок и предел истории, отдельные источники и максимум подсказок, очистка истории
  / cookie при выходе, Do Not Track и отправка Referrer.
- **Разрешения:** popup / JS dialogs, notification, geolocation, camera, microphone, clipboard, MIDI,
  sensors. Разрешения запрашиваются собственным диалогом Aura; новые значения Block применяются
  к content settings текущих origin и новых навигаций. Камера / микрофон не получают автоматического
  разрешения. Выбор источника захвата экрана не реализован, такие запросы отклоняются.
- **Загрузки:** абсолютный путь папки, запрос имени файла собственным диалогом, префикс даты,
  уведомление о завершении и автоматическое скрытие панели. Совпадающие имена не перезаписываются.
- **Данные:** очистка Aura history / cookie / HTTP cache, сброс настроек; очистка завершённых
  download entries не удаляет сами файлы.

## Применение

UI, профиль, вкладки, DNT / Referer и permission policy меняются сразу. Масштаб применяется также
к открытым страницам. Неизменяемые CefBrowserSettings подписаны «Для новых вкладок» и применяются
к новым CEF browser instances. Предпочтительный язык сайтов задаётся CefSettings и private request
context; его изменение требует перезапуска. Нельзя обещать, что сайт выберет запрошенный язык.

ContentSettings использует допустимые значения и области из
[Chromium ContentSettingsRegistry](https://github.com/chromium/chromium/blob/main/components/content_settings/core/browser/content_settings_registry.cc).
Доступная поверхность API сверена с закреплёнными заголовками CEF в third_party/src/cef-linux64/include.
Значения Ask / Block поддерживаются для разрешений; для датчиков UI предлагает Allow / Block.
Сайты дополнительно ограничены secure context, permissions policy и возможностями ОС / оборудования.
DNT — заголовок запроса, не реализация блокировщика трекеров.

Схема профиля 3. Отсутствующие поля получают прежние значения; неверные числа, перечисления,
домашние URL и относительные пути загрузок отклоняются. Atomic save заменяет файл только после
успешной записи. Приватные URL не попадают в сохраняемую сессию и историю.
Очистка при выходе завершается до CefShutdown; при аварии / SIGKILL её завершение не гарантируется.

## Код и проверка

- core/browser/preferences.* — каталог, типы и валидация 61 параметра.
- profile.* — миграция, срок / предел истории и источники подсказок.
- browser.* — startup / tabs / downloads / cleanup / async callbacks.
- client.* — CEF permissions, popup / dialogs, атомарный network policy для IO thread.
- ui/browser_ui.* — поиск, категории, типизированные контролы и текстовые поля.
- i18n.cpp — русские подписи и описания.
- tests/common_tests.cpp — roundtrip всех параметров, валидация, миграция, сроки / источники, перевод.
- scripts/smoke_settings.py — настоящий ввод и клики, проверки через CEF и локальные HTTP probes.

```bash
cmake --build --preset linux-x64-release --parallel 4
ctest --preset linux-x64-release --output-on-failure
python3 scripts/verify_browser.py --suite=all
./run.sh
```

Для GUI используется только собственный Weston headless / Pixman + Xwayland SHM, GLX выключен.
Реальный рабочий стол не используется. Аппаратный путь остаётся выключенным по умолчанию.
Отчёты: artifacts/settings-smoke/verification.json, artifacts/browser-smoke/verification.json,
artifacts/build/settings-expanded-*.log. Снимки UI находятся в artifacts/settings-smoke/.

## Результаты 18.10.2026

- Release build Linux: успешно, без предупреждений в финальной сборке.
- CTest: 24/24 (23 C++ теста и Python bootstrap suite).
- Каталог: roundtrip и валидация всех 61 параметров; сохранение старых профилей, ограничения
  истории и источников подсказок, наличие русских описаний проверены тестами.
- Браузерный GUI-сценарий: навигация, DOM input, вкладки, bookmark/find, JS dialog, download,
  private cookie isolation и session restore; lifecycle CEF 4/4 и 2/2.
- Сценарий настроек: два запуска, полное совпадение сохранённых параметров после перезапуска;
  lifecycle CEF 5/5 и 1/1, renderer crashes 0.
- HTTP probe подтвердил моноширинный шрифт 20 px, минимум 8 px, выключенные изображения
  и Local Storage; JavaScript проверен в выключенном и включённом состоянии.
- Запросы probe содержали DNT=1 и не содержали Referer; программное popup-окно не создало вкладку.
- Запрос notifications показал собственный диалог, отказ вернул странице denied; выключенные
  JS dialogs подавили alert без блокировки страницы.
- UTF-8 путь папки введён через clipboard собственного виртуального дисплея. Имя chosen.bin
  введено в собственный диалог; дата добавлена, 29 696 байт полностью совпали с payload.
  После завершения загрузки панель скрылась по настройке.
- Clear cache / cookies дождались CEF callbacks; cookie-check не увидел удалённую cookie.
  При обычном выходе заранее созданные история и cookie очищены; новый запуск не получил старую cookie.
- Startup home page и русский navigator.languages сработали после перезапуска; новые вкладки
  открыли домашнюю и пустую страницы по выбору. Reset вернул defaults и сохранил bookmark.
- Просмотрены русский интерфейс в светлой теме, английский в тёмной и русский при 900×620; нижние настройки доступны.

Камера, микрофон, геолокационный сервис, MIDI и физические датчики требуют аппаратных проверок;
в этом прогоне устройства не открывались. Не заявляется равенство всем настройкам Firefox.
