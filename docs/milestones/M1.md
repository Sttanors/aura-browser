# M1 — браузерная оболочка Linux

## Результат

`run.sh` запускает `aura_browser`, а не диагностический executable. В приложении работают
настоящие CEF-вкладки, редактируемая адресная строка, навигация и собственный интерфейс Skia.
Тестовая HTML-страница не является оболочкой: она используется только как посещаемый контент тестов.

Реализованы: sidebar tabs и их reorder, pin/mute/duplicate, Ctrl+T/W/Shift+T, открытие target=_blank,
URL/search и подсказки из истории/закладок, back/forward/reload/stop, favicon/title/progress,
NTP, persistent CEF cache/cookies, история/закладки/настройки, приватный request context,
загрузки с pause/resume/cancel, find-in-page, native Skia context menus и JavaScript dialogs,
DevTools и вызов CEF print.

## Проверка 18.10.2026

Среда после перезагрузки: CachyOS, kernel 7.2.9-2-cachyos, NVIDIA Open Kernel Module 615.78.08,
RTX 5060 Ti, Wayland/XWayland. Версии прочитаны из uname и /proc/driver/nvidia/version.

После сообщения пользователя о полном зависании машины при выборе тестового окна в taskbar
проверки на реальном рабочем столе прекращены. Отсутствие реакции на Ctrl+Alt+F3 зафиксировано
со слов пользователя. Точная причина не установлена: при последующей проверке journalctl
не находил запись предыдущей загрузки. Считать инцидент устранённым нельзя.

Аппаратное ускорение отключено по умолчанию в обоих Linux executables:

- BrowserWindow / LinuxDiagnosticWindow пропускают EGL initialization и используют Skia raster / XPutImage.
- CEF получает disable-gpu, disable-gpu-compositing и disable-accelerated-video-decode/encode.
- Chromium sandbox остаётся включённым.
- GPU возможен только по явному экспериментальному --gpu; повторной аппаратной проверки не было.

Дальнейший GUI-сценарий выполнен на отдельном виртуальном дисплее:
Weston 15.0.1 headless / Pixman + Xwayland SHM, GLX disabled.
DISPLAY и XDG_RUNTIME_DIR принадлежат временному окружению теста, не пользовательскому desktop.

## Повторение без использования рабочего стола

```bash
cmake --build --preset linux-x64-release --parallel 4
ctest --preset linux-x64-release
python3 scripts/verify_browser.py
```

`smoke_browser.py` и `smoke_window.py` защищены от прямого запуска на desktop.
Временные compositor/X server завершаются wrapper-скриптом; настройки сессии пользователя не меняются.

## Ограничения

Это рабочее браузерное ядро и оболочка, но не завершение всех требований большого MVP.
Нет менеджера паролей, CRX/MV3 installation UI, adblock, auto-update, sync, полноценной локализации
и переноса вкладок между окнами. Нормальный браузерный target пока Linux-only.
Private browsing реализован вкладками; общий private context существует в памяти до выхода из процесса.
Session restore сохраняет URL/порядок/pin и активную вкладку, но не весь navigation stack.
Clear Aura history очищает собственный список, а не cookies и внутренние данные Chromium.
Native Wayland, Vulkan, production render thread, accessibility и полный CJK IME требуют следующих этапов.
Reorder/pin/mute/context-menu/DevTools/print пути реализованы; перечисленный GUI smoke покрывает
только указанные в таблице сценарии. Работа на физическом GPU и безотказность desktop не подтверждены.
