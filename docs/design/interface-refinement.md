# Aura: уточнение интерфейса

Основа: пользовательский GUI Genius (`/home/user/Загрузки/SKILL.md`), 19.10.2026.

Aura — повседневный настольный браузер для Linux. Пользователь переключается между
сайтами, поиском и управлением браузером. Главная задача оболочки — открыть нужную
страницу и сохранить понятное положение вкладок и настроек.

## Решения до реализации

Палитра Aurora dark: фон #0D111B, поверхность #182033, текст #EDF3FF,
вторичный текст #99A7C1, акцент #A7B6FF. Остальные пять тем сохраняются.
Inter Variable: пояснения 12, основной текст 14, подзаголовки 18,
заголовки панелей 24, приветствие 32 px с уменьшением по доступной ширине.
Отступы кратны 4 px. Цвета и радиусы хранятся в design/tokens.json.

```
[ Aura / вкладки ] [ навигация | адрес | действия ]
[ Новая вкладка  ] [                             ]
[ вкладки       ] [ страница / новая вкладка     ]
[               ] [                             ]
[ панели        ] [ настройки: раздел | поля     ]
```

Это оболочка браузера: знакомая навигация, постоянные координаты основных действий,
вертикальные вкладки. Поэтому вместо общего карточного редизайна сохранены геометрия
и характер Aura. Выразительный акцент остаётся на выбранной вкладке; прочая оболочка
становится спокойнее. Настройки используют ровные строки, а не дополнительные карточки.

## Изменения

- Убраны декоративное зерно, рекламная подпись внизу новой вкладки и прописной
  слоган под логотипом. Тени стали меньше и легче, радиус панелей — 16 px.
- Выбранная вкладка прокручивается в видимую часть списка; частичные строки не рисуются.
- Приветствие вписывается в доступную ширину. Поле поиска и быстрые ссылки
  учитывают ширину окна; их области клика совпадают с отрисовкой.
- Панель настроек называется «Настройки». Пояснения и варианты увеличены;
  выбранные варианты имеют галочку, переключатели и поля — заметные границы.
  Прокрутка контрастнее, край содержимого отделён от закреплённых областей.
- Ошибка домашнего адреса или папки показана рядом с полем. Неудачное сохранение
  сохраняет редактируемую строку; Tab не закрывает поле с ошибкой.
  Пустой результат поиска предлагает другой запрос или выбор раздела.
- F10 переносит фокус в оболочку. Tab / Shift+Tab обходят видимые нативные действия;
  Enter / Space активируют их. Видимая рамка фокуса работает в настройках,
  менеджере расширений, списках, меню и диалогах. PageUp / PageDown / Home / End
  прокручивают панели; скрытые элементы становятся доступны после прокрутки.
  На обычной странице Tab по-прежнему обрабатывает сайт. Escape возвращает фокус сайту.
- У кнопок навигации и инструментов есть подписи с сочетаниями клавиш при наведении.
- Менеджер расширений показывает состояние вместо служебного ID. Недоступные
  popup/options и загрузка во время проверки выглядят неактивными.
  Закрепление и переход в магазин не конкурируют заливкой с основным действием установки.

## Проверка и границы

Release + CTest; GUI в отдельном Weston Pixman / Xwayland SHM, GLX отключён,
с отдельными профилями. Скрипт smoke_settings.py проверяет клавиатуру,
ошибку адреса и новую вкладку 900×620 в обеих яркостях темы.
Снимки: artifacts/settings-smoke и artifacts/features-smoke.

Это собственная оболочка Skia, а не DOM. Полноценный AT-SPI accessibility bridge
для нативной оболочки пока отсутствует; клавиатурный обход не заменяет его.
Мобильная компоновка неприменима: поддерживаемый минимум настольного окна 900×620.
Масштабирование всей оболочки до 200% отдельно в этой проверке не проверялось.
С реальными пользователями полезно проверить поиск редко используемых настроек,
обнаружение F10 и различимость неактивных действий во всех шести темах.

## Подписи кнопок

Отдельная проверка по замечанию пользователя: фиксированный baseline +23 px и
левый отступ в кнопках расширений заменены общим выравниванием по метрикам Inter
и реальной высоте кнопки. Тот же расчёт применён к диалогам, вариантам и сохранению
настроек, числовым регуляторам, установке из магазина и повтору загрузки страницы.
Галочка получает симметричный резерв места, поэтому подпись остаётся по центру.
Колонки вариантов учитывают измеренную длину перевода; кнопка закрепления расширения
расширена до 128 px, чтобы английское Unpin extension помещалось полностью.

GUI-сценарий features сохраняет permission-buttons-* и extension-buttons-* для
RU/EN при 1360×900 и 900×620, а также button-settings-language-* и popup-confirm-buttons.png.
