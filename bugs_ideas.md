## Баги

Две проблемы подтверждены отдельной проверкой. Остальные выявлены анализом кода;
их пользовательские сценарии ещё нужно воспроизвести в GUI.

### 1. Повреждённый профиль блокирует запуск

**На момент аудита:** подтверждено отдельной проверкой.

Ошибка синтаксиса в `profile.toml` вызывает исключение при создании профиля.
Нет восстановления из копии или возможности запуститься с временными настройками.

Сценарий: синтаксически повреждённый TOML → создание `Profile` → исключение без
резервного пути загрузки.

Код: [core/browser/profile.cpp](core/browser/profile.cpp), `Profile::load()`.

### 2. Выход из всего браузера обходит предупреждения о несохранённых данных

**На момент аудита:** выявлено по коду; требуется GUI-проверка. **Высокий приоритет.**

`request_exit()` закрывает окна через `request_quit(true)`, затем вызывается
`CloseBrowser(true)`. Пользователь может потерять заполненную форму, хотя обычное
закрытие вкладки предусматривает подтверждение `beforeunload`.

Сценарий для проверки: открыть форму с изменениями и обработчиком `beforeunload`,
затем выполнить выход из всего браузера.

Код: [core/browser/browser.cpp](core/browser/browser.cpp),
`BrowserController::request_exit()` и `BrowserController::request_quit()`.

### 3. Нарушена семантика window.open()

**На момент аудита:** выявлено по коду; требуется GUI-проверка.

Aura отменяет создание настоящего popup и отдельно открывает вкладку. Связь с
родительским окном и возвращаемый объект окна не сохраняются. Это может ломать
авторизацию, оплату и сценарии с `window.opener`/`postMessage`.

Сценарий для проверки: родительская страница вызывает `window.open()`, затем
обменивается сообщениями с открытым окном и использует возвращённый объект.

Код: [core/browser/client.cpp](core/browser/client.cpp),
`BrowserClient::OnBeforePopup()`.

### 4. Переход на стартовую страницу нарушает историю и состояние звука

**На момент аудита:** выявлено по коду; требуется GUI-проверка.

При переходе на `aura://newtab` старый сайт только скрывается и принудительно
заглушается. Стартовая страница не становится записью истории CEF. Последующее
«Назад» вызывает `GoBack()` старого сайта и может пропустить последнюю страницу.
В этой ветке звук также не восстанавливается.

Сценарий для проверки: перейти с сайта A на сайт B, открыть `aura://newtab` в той
же вкладке, затем нажать «Назад» и проверить адрес, содержимое и звук.

Код: [core/browser/browser.cpp](core/browser/browser.cpp),
`BrowserController::navigate()`, `back()` и `forward()`.

### 5. После отмены закрытия вкладка остаётся в списке закрытых

**На момент аудита:** выявлено по коду; требуется GUI-проверка.

Запись в `recently_closed_` добавляется до подтверждения `beforeunload`. Если
пользователь решит остаться, `Ctrl+Shift+T` сможет открыть дубликат всё ещё
существующей вкладки.

Сценарий для проверки: попытаться закрыть вкладку с несохранённой формой,
отменить закрытие и нажать `Ctrl+Shift+T`.

Код: [core/browser/browser.cpp](core/browser/browser.cpp),
`BrowserController::close_tab()`, `answer_dialog()` и `reopen()`.

### 6. Адресная строка ошибается при распознавании ввода

**На момент аудита:** подтверждено отдельной проверкой `navigation_url()`.

| Ввод | Фактический результат | Проблема |
|---|---|---|
| `[2001:db8::1]` | Поиск DuckDuckGo | IPv6-адрес без схемы не распознаётся |
| `intranet:8080` | Поиск DuckDuckGo | Локальное имя с портом не распознаётся |
| `1.5+2.5` | `https://1.5+2.5` | Арифметическое выражение принимается за адрес |

Правило «есть точка — значит адрес» слишком грубое.

Код: [core/browser/profile.cpp](core/browser/profile.cpp), `navigation_url()`.

### 7. Вставка большого текста на Linux может возвращать пустую строку

**На момент аудита:** выявлено по коду; требуется GUI-проверка.

Обработчик буфера обмена не поддерживает передачу X11 `INCR`, которую приложения
используют для больших данных. Остаток данных `after` также не дочитывается.

Сценарий для проверки: скопировать большой текст из внешнего приложения,
использующего `INCR`, и вставить его в поле Aura; сравнить содержимое и длину.

Код: [platform/linux/x11/browser_window.cpp](platform/linux/x11/browser_window.cpp),
обработка `SelectionNotify` и `BrowserWindow::paste()`.

### 8. Конфликт .run и системного пакета остаётся возможным

**На момент аудита:** ранее воспроизведено на пользовательской системе; локально исправлено,
но установщики не предотвращают повторение у других пользователей.

Старый пользовательский desktop entry перекрывает системный и продолжает
запускать прежнюю `.run`-установку. Новый пакет при этом может быть установлен
правильно. Защита сейчас ограничивается инструкцией о миграции в README.

Сценарий: установить старую `.run`-версию, затем системный пакет без удаления
пользовательской установки и запустить Aura из меню приложений.

Код: [packaging/linux/install.sh](packaging/linux/install.sh) и
[packaging/linux/native/aura-browser.desktop](packaging/linux/native/aura-browser.desktop).

## Предлагаемый порядок исправлений

1. Сохранность данных: предупреждения при выходе и восстановление повреждённого профиля.
2. Совместимость `window.open()` и обмена сообщениями между окнами.
3. История и звук при переходе на стартовую страницу.
4. Список закрытых вкладок, распознавание адресов и буфер обмена Linux.
5. Предотвращение конфликта пользовательской и системной установок.

## Идеи новых функций

Реализация начата по запросу владельца: статус каждого пункта и результаты проверок
ведутся в [журнале функций](docs/features-progress.md). Таблица ниже сохраняет исходный объём идей.

| № | Функция | Польза и предполагаемый объём |
|---|---|---|
| 1 | Рабочие пространства | Отдельные наборы вкладок для работы, учёбы и личных задач; переключение и сохранение состояния |
| 2 | Группы вкладок | Имена, цвета и сворачивание больших наборов страниц |
| 3 | Спящие вкладки | Освобождение памяти с исключениями для музыки и важных сайтов |
| 4 | Две страницы рядом | Сравнение документов и работа с источниками без второго окна |
| 5 | Контейнеры сайтов | Несколько аккаунтов одного сервиса с раздельными cookies |
| 6 | Полноценные профили | Отдельные настройки, история, расширения и пароли |
| 7 | Палитра команд | Быстрый поиск вкладок, настроек и действий с клавиатуры |
| 8 | Режим чтения | Чистый текст статьи, настройка шрифта и ширины строки |
| 9 | Перевод страниц и выделения | Выбор языка и провайдера перевода |
| 10 | Центр разрешений сайта | Просмотр и отзыв доступа к камере, микрофону и другим возможностям |
| 11 | Панель данных сайтов | Просмотр размера хранилищ и удаление данных конкретного домена |
| 12 | Менеджер закладок | Папки, теги, поиск, массовые действия и экспорт |
| 13 | Снимки сессий | Ручное сохранение и восстановление именованных наборов окон |
| 14 | Скриншоты страницы | Захват области, видимой части или всей страницы |
| 15 | Настраиваемые горячие клавиши | Переназначение команд с обнаружением конфликтов |

Для ближайшего этапа наиболее полезны **спящие вкладки, рабочие пространства,
центр разрешений и менеджер закладок**. Реализацию функций следует планировать
после устранения ошибок, связанных с потерей данных и базовой навигацией.
